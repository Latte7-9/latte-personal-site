# Tarot Card Image Sources

The card face images in `images/tarot/cards/` are Rider-Waite-Smith deck scans downloaded from:

- Repository: https://github.com/metabismuth/tarot-json
- Image path: `cards/*.jpg`
- Project license: MIT
- Source note from the project README: RWS deck scans, 350x600px each

The upstream README states that the Rider-Waite-Smith deck is public domain in the US and that copyright status may differ by region. Keep this note with the image assets.
